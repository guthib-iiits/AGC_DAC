# AGC_DAC
This is a breadboard project for a bluetooth dac. I lost almost al of the files but found a very very very old one as a restored version. I want to make a device like Astell and Kern XB10 Bluetooth DAC , which I very much admire , but given my knowledge in Embedded Systems and know VLSI knowledge at that time , this was the only option I had.
Uses ESP32 and PCM5102 Breakout along with discrete ADC and gives out 44.1KHz 24 bit audio to the Ahuja System. Worked quite well in all the tested rooms.
Also working properly for almost any 3.5mm device , could not figure out why they were not working on my IEMs though , might be bad impedence matching.
This project also gives input to matlab and they communicate to supress Gain using a PID controller in matlab for attack and release rates , and I lost those files unfortunately.
